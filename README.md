##  Featured Projects

### Centro Médico Integral 🏥
**Production-grade medical records management system for Argentine healthcare facilities**

A comprehensive system for managing medical histories, appointments, patients, and healthcare professionals. Compliant with Argentine data protection laws (Ley 25326, Ley 26388).

**Tech Stack:** Django 4.2 | PostgreSQL 15 | Docker Compose | Nginx | Claude Vision API

**Key Features:**
- Digital medical records with AI-powered image processing
- Appointment scheduling with automated availability validation
- Patient management with advanced search
- Role-based access control (doctor, receptionist, admin)
- Complete audit logging
- Automated daily backups
- HTTPS with automatic certificate management

**Links:** [GitHub](https://github.com/Tomas-Ojeda/Centro-Medico-Integral) | [Live Demo](#) (Coming soon)

### ExtracText 
**University team project: Multi-tenant document processing platform**

A full-stack system for extracting and processing text from various document formats. Built as a semester-long team project emphasizing DevOps, microservices architecture, and production-ready deployment.

**Tech Stack:** Python | Docker Compose | Traefik | MongoDB | Clean Architecture

**Key Features:**
- Multi-service Docker orchestration with Traefik reverse proxy
- HTTPS with self-signed certificates (mkcert)
- Team collaboration with Git workflow
- Scalable document processing pipeline
- Service-oriented architecture
